Per-Game Scoped Documentation Modules

Each game submodule under EngineApps/Games/Lego/Games/ maintains its own standalone reversing/docs/index.html covering only the format versions observed in that title (sufficient to implement a clean-room parser for that game without needing cross-era history):

  • Games/Lego_Harry_Potter/reversing/docs/index.html — NXG HSEM v0x04/0x05 (Years 1–4) & v0x2E/0x2F (Years 5–7), PakDat v1.01, and Collection .datwin.
  • Games/Lego_Pirates_of_the_Caribbean/reversing/docs/index.html — NXG HSEM v0x2E/0x2F.
  • Games/Lego_Batman/reversing/docs/index.html — NXG HSEM v0x2E/0x2F/0x30 and PakDat v1.01.
  • Games/Lego_Marvel_Super_Heroes/reversing/docs/index.html — NXG HSEM v0x30.
  • Games/Lego_Dimensions/reversing/docs/index.html — Era 4 HSEM v0xA1..0xAD+ (DXTV/ROTV), .HDR + CMP2, and NFC Toy Tags.
  • Games/Lego_Worlds/reversing/docs/index.html — Era 4 DX11 HSEM (DXTV), voxel chunks, and .lxfml blueprints.
