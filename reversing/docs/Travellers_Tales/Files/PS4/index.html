PlayStation 4 (Orbis) Filesystem & Binary Notes

Inspected Directly (Unencrypted Metadata): LEGO Worlds CUSA02985 Base v01.00, Update v01.12, and Classic Space DLC \x7fCNT fPKGs.

PlayStation 4 packages use big-endian \x7fCNT containers wrapping unencrypted PlayGo/SFO/ATRAC9/DDS/Trophy metadata alongside an AES-XTS encrypted outer/inner PFS filesystem (magic=20130315, mode=0x000D, block_size=0x10000).
