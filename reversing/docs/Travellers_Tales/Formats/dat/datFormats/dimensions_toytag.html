NTAG213 Memory Map (45 Pages × 4 Bytes)

LEGO Dimensions NFC Tag EEPROM Page Layout
Page Index Byte Offset Field Encoding / Encryption
0x00..0x02 0x00..0x0B UID[0..6] + BCC + Internal + Lock Immutable NXP hardware serial bytes used as seed for TEA key schedule & page 0x2B password.
0x24..0x25 0x90..0x97 Encrypted ID / Vehicle Block 8 bytes decrypted via 32-round TEA (`delta = 0x9E3779B9`) with 128-bit key derived from UID; yields 16-bit/32-bit character/vehicle ID (or 0 for blank vehicle tag).
0x26 0x98..0x9B VehicleTagType / Magic Tag classification flags separating ToyTag characters (read-only ID in 0x24/0x25 via host key) vs writable Vehicle/Gadget Toy Tags (`0x00010000` marker).
0x27 0x9C..0x9F Encrypted Upgrade Bitfield 2 Secondary writable gadget upgrade states.
0x2B 0xAC..0xAF PWD (Write Password) 4-byte derived NTAG213 password verified by the USB ToyPad portal (`PWDGEN`).

Exact Key Derivation & Password Formula

For a 7-byte UID padded/mixed with constants into uint32[4] key, each word i iterates an order-dependent ROL32/XOR mixing schedule (matching community ToyPad protocol documentation). Character IDs are read from pages 0x24..0x25 after TEA decryption, while the USB portal communicates over HID interrupt packets using frame magic 0x55 (command) / 0x56 (event).

Standalone Clean-Room Parser Pseudocode

function TeaDecryptBlock(v0, v1, k):
    sum = 0xC6EF3720; delta = 0x9E3779B9
    for _ in 0 .. 31:
        v1 = (v1 - (((v0 << 4) + k[2]) ^ (v0 + sum) ^ ((v0 >> 5) + k[3]))) & 0xFFFFFFFF
        v0 = (v0 - (((v1 << 4) + k[0]) ^ (v1 + sum) ^ ((v1 >> 5) + k[1]))) & 0xFFFFFFFF
        sum = (sum - delta) & 0xFFFFFFFF
    return (v0, v1)
