.tsh (Texture Share / Atlas Lookup Table)

Category: Textures & Materials · Scope: Era 3–4 (HP 1–4, HP 5–7, Batman 2, Dimensions)

Format Specification · TT Games Engine

Texture sharing and atlas indirection container (TSHR / RHST) mapping shared minifigure decals and common material surfaces across character packages.

.tsh

Overview

.tsh files use the NU20 / 02UN chunk container with a primary TSHR (LE) / RHST (BE) chunk to alias shared textures across multiple character or level directories without duplicating pixel data in VRAM.
