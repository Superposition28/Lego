.tsh Inner Structure
Offset Type / Magic Field / Content
0x00..0x0F u32be sz, .CC4HSERHSER Outer HSER v6 envelope + ROTV + build tag (Trunk_QA, user string).
0x4B..0x5F .CC4HSXTHSXT + u32be 4 Texture sheet descriptor header + ROTV.
0x64..0x9F f32be[4] + dims Normalized UV rectangle bounds (e.g. 0.406..0.57), stride flags, "1TXD" magic tag per atlas/sub-rect.

Standalone Clean-Room Parser Pseudocode

function ParseTsh(buf):
    if buf[4:12] != b".CC4HSER": raise InvalidTsh
    hsxt = FindTag(buf, b".CC4HSXT")
    txd_tags = FindAll(buf[hsxt:], b"1TXD")
    return {hsxt_off: hsxt, sub_images: len(txd_tags)}
