Standalone Clean-Room Parser Pseudocode

function ParseBamlHeader(buf):
    if buf[4:16] == b"M\0S\0B\0A\0M\0L\0": return {kind: "Microsoft_WPF_MSBAML"}
    return {kind: "TT_LayoutRoot", has_root: b"LayoutRoot" in buf}
