Documentation/Formats/.dat/.ghg

.ghg / .hgx / .hx2 / .hgp (Game Hierarchical Geometry / Skeletal Model)

Category: Characters & Models · Scope: Universal (All TT Engine Generations 2005–2024; .hgx in LSW1 Xbox, .hx2 in LSW2 Xbox, .hgp in LSW1 PC/GCN; _nxg.ghg / _dx11.ghg in Era 3–4)

Cross-Generation Master Specification · TT Games Engine

Skeletal character, minifigure, creature, vehicle, and hierarchical prop model format. This parent document combines every generation of .ghg across TT Games titles into a complete standalone specification, enabling a developer to implement a full multi-era parser and exporter from scratch without reading external code. For single-title parser implementations scoped strictly to one game's binary variant, refer to that title's Games/<Game>/reversing/docs/Formats/dat/datFormats/ghg.html.

2.1 GSNH Skeleton, Rigid Inverse-Bind Matrices & NuLayer Hierarchy

Locate "GSNH" inside tail = bytes[nu_off..]. Signed 32-bit offsets inside GSNH resolve from their own field byte offset (target = field_offset + int32le(tail, field_offset)):

Offset from gsnhSizeTypeFieldResolution & Usage
+280 (0x118)4int32ler280Display Header at hdr_off = gsnh + 280 + r280: cmd_base = (hdr_off + 8) + i32(hdr_off + 8), n_groups = i32(hdr_off + 16), p_groups = (hdr_off + 20) + i32(hdr_off + 20).
+368 (0x170)4uint32lenbonesBone count (1..512).
+380 (0x17C)4int32ler380Inverse-bind array m2_ptr = gsnh + 380 + r380 of nbones 64-byte row-major float32le[16] matrices. Rigid bone parts use WorldBind[b] = (m2[b])^-1.
+408 / +4124 + 4u32le / i32len_layers / r412p_layers = gsnh + 412 + r412 points to n_layers 20-byte NuLayer entries.
  • NuLayer (20 B = 5 * int32le): (name_rel, r_rel, s_rel, rl_rel, sl_rel). Skip lowercase names containing breakup, medium, medres, _med, low, lores, verylo, _vlo, _lo, c3po, or matching (^|_)tt[234](_|$). Prefer r_rel (+4 rigid bone pointer array) & s_rel (+8 skinned slot), falling back to rl_rel (+12) & sl_rel (+16) only when both r_rel == 0 and s_rel == 0.
  • Display Group (12 B): +0x00 int32le cnt, +0x04 int32le mtls_rel -> int32le mtls[cnt] material table indices, +0x08 int32le cmds_rel -> cnt command indices into 16 B command records (opcode, desc_rel, z0, z1) -> 56 B draw descriptor (14 * int32le) at c_off + 4 + desc_rel: desc[0] (4/5=List, 6=Strip), desc[1]=tri_cnt, desc[2]&0xFF=stride (24..48; desc[2] > 0 or stride >= 40 indicates trailing 8-byte skin weights/bone indices), desc[5]=vbase, desc[6]=vcnt, desc[7]=ioff, desc[8]=ib_idx, desc[9]=vb_idx.
  • NU20 0x380 Material Records: Scan 16 B commands at cmd_base until opcode == 0x8E. Every command with opcode == 0x380 resolves a material struct at mo = c_off + 4 + c1: +0x54 float32le[3] rgb (diffuse color factor) and +0x74 int16le tid (-1 if untextured, else logical texture slot in the pre-NU20 InlineDDS table, where cubemaps with width_signed < 0 consume 6 slots and 2D textures consume 1).
  • NU20 Vertex Stride Offsets: is_skinned_fmt = (desc[2] > 0) or (stride >= 40). When stride >= 28, UV0 is at uv_off = (stride - 16) if is_skinned_fmt else (stride - 8) (top-left origin), and 4-byte vertex color sits immediately before UV0 at col_off = uv_off - 4 (or stride - 4 when stride == 24).

4. Materials, Embedded DDS Textures & Shading Model

Across inspected Classic NU20 (LSW) and Next-Gen HSEM (HP 1–7, Batman 2) containers, final LEGO surface color follows a single unified product:

FinalAlbedo = MaterialColor * VertexColor * DiffuseTexture_DDS
Chunk / StageScope & LayoutParsing & Filtering Rules
DDS Payload & DDSD_LINEARSIZE QuirkWhole file (up to 64 MB in HSEM)Embedded textures use standard 128-byte "DDS \x7c\x00\x00\x00" headers (DXT1/DXT3/DXT5 or uncompressed). In Next-Gen HSEM, scan [0..hsem_pos] and [psid..EOF] for valid headers (1 <= w,h <= 8192) and slice to min(next_dds, dpos + calc_dds_bytes). In several Era 3b/3c files (e.g. HP 5–7, Batman 2), DDSD_LINEARSIZE (0x00080000 in flags @ +0x08) is set while dwPitchOrLinearSize @ +0x14 stores a wrong uncompressed size; patch +0x14 to mip0_bytes = max(1,(w+3)>>2)*max(1,(h+3)>>2)*blk before decoding. Alpha channels often store gloss/specular masks — render diffuse materials opaque by default.
ATEM (META Reversed) Texture NamesNext-Gen HSEM (typically after PSID)"ATEM" + u32be ver + optional "ROTV" + u32be n_nut + n_nut * [u32be slen, ascii[slen]]. Index-aligned 1-to-1 with extracted DDS slices. Normalize \ -> / and strip trailing NUL bytes; reject non-diffuse maps matching /undersides/, mask_, sbmask_, /normals/, _n.nut, _nrm.nut, specular, dummylightmap, or capenormal.
PSID (DISP Reversed) MappingNext-Gen HSEM (`mesh_idx -> mtl_idx`)"PSID" + u32be p_ver + optional "ROTV" + [u32be slen, path[slen]] + optional "ROTV" + u32be n_ops + n_ops * 6B (u16be op, u32be arg) + optional "ROTV" + u32be n_grp. Each group stores u16be flag, u32be nm, u32be mtls[nm], u32be nc, u32be cmds[nc]. For each pair (m_idx, c_idx), probe delta in {0, 1, -1} for ops[c_idx + delta].op == 0xB300 and bind mesh_to_mtl[ops[c_idx + delta].arg] = m_idx.
LTMU (UMTL Reversed) Materials"LTMU" .. "TDML" / "PSID"Header: "LTMU" + u32be l_ver + optional "ROTV" + u32be n_mtl.
• Early (l_ver <= 0x20, e.g. 0x0F, 0x15): Locate n_mtl anchors matching 7f 7f 7f ff repeated 3 times (taking hits spaced >= 32 bytes apart; 684 B stride in v0x15, 708 B in v0x0F). Relative to mo = hit - 0x74: tid = int16be(mo + 0x61); if textured (valid diffuse tid >= 0), use white (1,1,1) albedo factor; otherwise decode uint8 B,G,R @ mo+0x70 as (R/255, G/255, B/255) when not 7f 7f 7f and non-zero, else (when l_ver >= 0x15) decode float32be[3] @ mo+0x262.
• Mid/Late (l_ver > 0x20, e.g. 0x38..0x84): Locate n_mtl 40-byte sampler blocks (00 00 00 04 * 10). Immediately preceding are nslots = 16 if l_ver < 0x78 else 18 big-endian int32 texture indices. Use tslots[0] as diffuse tid unless tid == tslots[4] (stud underside mask) or filtered by ATEM name.

5. Vertex Attributes, Mathematical Decoding & Winding

  • TYPE_SIZES: [0, 4, 8, 12, 16, 4, 8, 4, 4, 4, 4, 2]. Semantic attr_def: 0=Position, 1=Normal, 2=VertexColor, 5=UV0. If vb0 lacks Normals, Colors, or UVs and vb1.nv == vb0.nv, source them from vb1 over vbase .. vbase + vcnt.
  • Vertex Colors (attr_def == 2, tp in {7,8,9}): 4-byte (R, G, B, aux) where 0x7F = 1.0. Decode as (min(1.0, b0/127.0), min(1.0, b1/127.0), min(1.0, b2/127.0)), defaulting to white (1,1,1) when b0 == b1 == b2 == 0 (uninitialized slot; fourth byte stores AO/weight rather than opacity).
  • Other Data Types & Winding: tp 3,4=Float3/Float4 (auto-detect LE vs BE across first 16 verts); tp 6=Half4 (>HHH IEEE-754 binary16); tp 7,8,9 normals=(b / 127.5) - 1.0; tp 2=Float2 (>ff); tp 5=Half2 (>HH binary16). Index values are 0-based relative to vbase and CCW-wound (flip to CW for Godot 4 SurfaceTool).

6. LOD, Breakup, Skeleton & Deduplication Rules

  • LOGH LOD 0 & Breakup Filtering: Keep the first ceil(len(submeshes) / n_logh) submeshes. If at least 3 submeshes in LOD 0 have blen > 0 (skinned limbs/torso), drop all unskinned breakup chunks (blen == 0).
  • Bounding-Box Deduplication: Deduplicate submeshes sharing (vcnt, tri_cnt, round(min_xyz,3), round(max_xyz,3)).

7. Complete Standalone Parser Pseudocode (Multi-Era .ghg)

CONST TYPE_SIZES = [0, 4, 8, 12, 16, 4, 8, 4, 4, 4, 4, 2]

function ParseGhgModel(bytes):
    prims = ParseNu20Character(bytes)
    if len(prims) > 0: return prims
    return ParseHsemStream(bytes)

// --- Shared Geometry & Math Helpers ---
function HalfToFloat(h):
    s = (h >> 15) & 1; e = (h >> 10) & 0x1F; f = h & 0x3FF
    if e == 0:  return 0.0 if f == 0 else (-1.0 if s else 1.0) * (f / 1024.0) * (2.0 ** -14)
    if e == 31: return 0.0
    return (-1.0 if s else 1.0) * (1.0 + f / 1024.0) * (2.0 ** (e - 15))

function DecodeTriangles(raw, vcnt, is_strip, clockwise_target):
    out = []; n = len(raw)
    if n < 3 or vcnt < 3: return out
    if is_strip:
        for s in 0 .. n - 3:
            a = raw[s]; b = raw[s+1]; c = raw[s+2]
            if 0 <= a < vcnt and 0 <= b < vcnt and 0 <= c < vcnt and a != b and b != c and a != c:
                ccw_even = ((s & 1) == 0)
                emit_abc = (ccw_even and not clockwise_target) or (not ccw_even and clockwise_target)
                out.extend((a, b, c) if emit_abc else (a, c, b))
    else:
        for i in range(0, n - (n % 3), 3):
            a = raw[i]; b = raw[i+1]; c = raw[i+2]
            if 0 <= a < vcnt and 0 <= b < vcnt and 0 <= c < vcnt and a != b and b != c and a != c:
                out.extend((a, c, b) if clockwise_target else (a, b, c))
    return out

function InvertRigidMat4x4(m):
    // Row-vector 4x4: rotation rows (m[0..2], m[4..6], m[8..10]), translation p=(m[12], m[13], m[14])
    r_inv = [m[0], m[4], m[8],  m[1], m[5], m[9],  m[2], m[6], m[10]]
    tx = -(m[12]*m[0] + m[13]*m[1] + m[14]*m[2])
    ty = -(m[12]*m[4] + m[13]*m[5] + m[14]*m[6])
    tz = -(m[12]*m[8] + m[13]*m[9] + m[14]*m[10])
    return (r_inv, [tx, ty, tz])

// --- Classic NU20 Helpers & Parser ---
function ResolveNuLayerItem(tail, item_ptr, p_groups, n_groups):
    if item_ptr < 0 or item_ptr + 180 > len(tail): return -1
    g_off = item_ptr + 176 + ReadI32LE(tail, item_ptr + 176)
    if g_off < p_groups or ((g_off - p_groups) % 12) != 0: return -1
    g_idx = (g_off - p_groups) / 12
    return g_idx if (0 <= g_idx < n_groups) else -1

function CollectNuLayers(tail, p_layers, n_layers, nbones, p_groups, n_groups, skip_filtered):
    collected = []
    for l_idx in 0 .. n_layers - 1:
        loff = p_layers + l_idx * 20
        name_rel, r_rel, s_rel, rl_rel, sl_rel = ReadI32LEArray(tail, loff, 5)
        lname = ReadNullTermAscii(tail, loff + name_rel).lower()
        if skip_filtered and (ContainsAny(lname, ["breakup","medium","medres","_med","low","lores","verylo","_vlo","_lo","c3po"]) or MatchesRegex(lname, "(^|_)tt[234](_|$)")):
            continue
        pairs = [(r_rel, 4, true), (s_rel, 8, false)]
        if r_rel == 0 and s_rel == 0: pairs.extend([(rl_rel, 12, true), (sl_rel, 16, false)])
        for (rel, f_off, is_rigid) in pairs:
            if rel == 0: continue
            if is_rigid:
                r_base = loff + f_off + rel
                for bi in 0 .. nbones - 1:
                    br = ReadI32LE(tail, r_base + bi * 4)
                    if br != 0:
                        t_ptr = r_base + bi * 4 + br
                        g_idx = ResolveNuLayerItem(tail, t_ptr + 8 + ReadI32LE(tail, t_ptr + 8), p_groups, n_groups)
                        if g_idx >= 0: collected.append((g_idx, bi))
            else:
                t_ptr = loff + f_off + rel
                g_idx = ResolveNuLayerItem(tail, t_ptr + 8 + ReadI32LE(tail, t_ptr + 8), p_groups, n_groups)
                if g_idx >= 0: collected.append((g_idx, null))
    return collected

function ParseNu20Character(bytes):
    if len(bytes) < 8: return []
    nu_off = ReadU32LE(bytes, 0x00) + 4
    if nu_off < 8 or nu_off + 8 > len(bytes) or bytes[nu_off : nu_off + 4] != "NU20": return []
    n_tex = ReadU16LE(bytes, 0x04); pos = 0x06; tex_idx = 0; dds_by_slot = {}
    while tex_idx < n_tex and pos + 28 <= nu_off:
        if bytes[pos + 24 : pos + 28] != "DDS ": break
        w_signed = ReadI32LE(bytes, pos); dds_size = ReadU32LE(bytes, pos + 20)
        if w_signed > 0 and dds_size > 128: dds_by_slot[tex_idx] = bytes[pos + 24 : pos + 24 + dds_size]
        tex_idx += (6 if w_signed < 0 else 1); pos += 24 + dds_size
    n_vb = ReadU16LE(bytes, pos); pos += 2; vbs = []
    for _ in 0 .. n_vb - 1: sz = ReadU32LE(bytes, pos); pos += 4; vbs.append(bytes[pos : pos + sz]); pos += sz
    n_ib = ReadU16LE(bytes, pos); pos += 2; ibs = []
    for _ in 0 .. n_ib - 1: sz = ReadU32LE(bytes, pos); pos += 4; ibs.append(ReadU16LEArray(bytes, pos, sz/2)); pos += sz
    if len(vbs) == 0 or len(ibs) == 0: return []

    tail = bytes[nu_off : len(bytes)]; gsnh = FindTag(tail, "GSNH")
    if gsnh < 0 or gsnh + 420 > len(tail): return []
    nbones = ReadU32LE(tail, gsnh + 368); world_binds = []
    if 0 < nbones <= 512:
        m2_ptr = gsnh + 380 + ReadI32LE(tail, gsnh + 380)
        for b in 0 .. nbones - 1: world_binds.append(InvertRigidMat4x4(ReadF32LEArray(tail, m2_ptr + b * 64, 16)))

    r280 = ReadI32LE(tail, gsnh + 280); hdr_off = gsnh + 280 + r280
    cmd_base = hdr_off + 8 + ReadI32LE(tail, hdr_off + 8)
    n_groups = ReadI32LE(tail, hdr_off + 16); p_groups = hdr_off + 20 + ReadI32LE(tail, hdr_off + 20)
    nu_mtls = []
    for ci in 0 .. 4095:
        co = cmd_base + ci * 16; c0, c1 = ReadI32LE(tail, co), ReadI32LE(tail, co + 4)
        if c0 == 0x8E: break
        if c0 == 0x380:
            mo = co + 4 + c1
            nu_mtls.append((ClampRGB(ReadF32LE3(tail, mo + 0x54)), ReadI16LE(tail, mo + 0x74)))

    n_layers = ReadU32LE(tail, gsnh + 408); r412 = ReadI32LE(tail, gsnh + 412)
    draw_groups = CollectNuLayers(tail, gsnh + 412 + r412, n_layers, nbones, p_groups, n_groups, true) if (n_layers > 0 and r412 != 0) else []
    if len(draw_groups) == 0 and n_layers > 0 and r412 != 0:
        draw_groups = CollectNuLayers(tail, gsnh + 412 + r412, n_layers, nbones, p_groups, n_groups, false)
    if len(draw_groups) == 0: draw_groups = [(g, null) for g in 0 .. n_groups - 1]

    draw_calls = []; seen_cmds = {}
    for (g_idx, bone_idx) in draw_groups:
        goff = p_groups + g_idx * 12; cnt = ReadI32LE(tail, goff)
        p_mtls = goff + 4 + ReadI32LE(tail, goff + 4); p_cmds = goff + 8 + ReadI32LE(tail, goff + 8)
        for k in 0 .. cnt - 1:
            m_idx = ReadI32LE(tail, p_mtls + k * 4); c_idx = ReadI32LE(tail, p_cmds + k * 4)
            if (c_idx, bone_idx) in seen_cmds: continue
            c_off = cmd_base + c_idx * 16; t_off = c_off + 4 + ReadI32LE(tail, c_off + 4)
            desc = ReadI32LEArray(tail, t_off, 14)
            if desc[0] in [4,5,6] and 0 < desc[1] < 200000 and (desc[2] & 0xFF) in [24,28,32,36,40,44,48]:
                seen_cmds.add((c_idx, bone_idx)); draw_calls.append((desc, bone_idx, m_idx))
    if len(draw_calls) == 0:
        for off in range(max(0, gsnh - 250000), gsnh, 4):
            c0, rel, z0, z1 = ReadI32LEArray(tail, off, 4)
            if c0 == 0x82 and z0 == 0 and z1 == 0 and 0 < rel < 200000:
                desc = ReadI32LEArray(tail, off + 4 + rel, 14)
                if desc[0] in [4,5,6] and 0 < desc[1] < 200000: draw_calls.append((desc, null, -1))

    out = []; seen_ranges = {}; seen_bboxes = {}
    for (desc, bone_idx, m_idx) in draw_calls:
        prim_tp = desc[0]; tri_cnt = desc[1]; stride = desc[2] & 0xFF
        vbase = desc[5]; vcnt = desc[6]; ioff = desc[7]; ib_idx = desc[8]; vb_idx = desc[9]
        if (vb_idx, vbase, vcnt, ioff, bone_idx) in seen_ranges: continue
        idx_cnt = (tri_cnt + 2) if prim_tp == 6 else (tri_cnt * 3)
        if (vbase + vcnt) * stride > len(vbs[vb_idx]) or ioff + idx_cnt > len(ibs[ib_idx]): continue
        R_inv, t_inv = world_binds[bone_idx] if (bone_idx != null and bone_idx < len(world_binds)) else (null, null)
        is_skinned_fmt = (desc[2] > 0) or (stride >= 40); has_uv = (stride >= 28)
        uv_off = (stride - 16) if is_skinned_fmt else (stride - 8)
        col_off = (uv_off - 4) if has_uv else (stride - 4)
        positions = []; normals = []; colors = []; uvs = []
        for vi in vbase .. vbase + vcnt - 1:
            vo = vi * stride; x, y, z = ReadF32LE3(vbs[vb_idx], vo)
            if R_inv != null: x, y, z = (x*R_inv[0]+y*R_inv[3]+z*R_inv[6]+t_inv[0], x*R_inv[1]+y*R_inv[4]+z*R_inv[7]+t_inv[1], x*R_inv[2]+y*R_inv[5]+z*R_inv[8]+t_inv[2])
            positions.extend((x, y, z))
            if stride >= 24:
                nx = vbs[vb_idx][vo+12]/127.5 - 1.0; ny = vbs[vb_idx][vo+13]/127.5 - 1.0; nz = vbs[vb_idx][vo+14]/127.5 - 1.0
                if R_inv != null: nx, ny, nz = (nx*R_inv[0]+ny*R_inv[3]+nz*R_inv[6], nx*R_inv[1]+ny*R_inv[4]+nz*R_inv[7], nx*R_inv[2]+ny*R_inv[5]+nz*R_inv[8])
                normals.extend(Normalize3(nx, ny, nz))
            if 16 <= col_off and col_off + 4 <= stride:
                b0, b1, b2 = vbs[vb_idx][vo+col_off], vbs[vb_idx][vo+col_off+1], vbs[vb_idx][vo+col_off+2]
                colors.append((1,1,1) if (b0==0 and b1==0 and b2==0) else (min(1.0,b0/127.0), min(1.0,b1/127.0), min(1.0,b2/127.0)))
            if has_uv: uvs.extend(ReadF32LE2(vbs[vb_idx], vo + uv_off))
        mtl_col, mtl_tex = ResolveNuMaterial(nu_mtls, dds_by_slot, m_idx)
        tris = DecodeTriangles(ibs[ib_idx][ioff : ioff + idx_cnt], vcnt, prim_tp == 6, clockwise_target=false)
        if len(tris) < 3: continue
        bbox = QuantizedBBoxKey(positions, vcnt, len(tris) / 3)
        if bbox not in seen_bboxes:
            seen_ranges.add((vb_idx, vbase, vcnt, ioff, bone_idx)); seen_bboxes.add(bbox)
            out.append((positions, normals, colors, uvs, tris, mtl_col, mtl_tex))
    return out

// --- Next-Gen HSEM Helpers & Parser ---
function IsHsemMeshStart(buf, pos, ver):
    if pos + 24 > len(buf): return false
    w0, w1, w2, w3 = ReadU32BEArray(buf, pos, 4)
    if 1 <= w0 <= 4:
        if 0xC0000000 <= w1 <= 0xC000FFFF and w2 == 1: return true
        if w1 == 1 and w2 in [1,2,32,33,34,36,0x100,0x104] and 3 <= w3 <= 500000:
            if ver < 0x2E:  return buf[pos+16] in [2,3,4,6] and buf[pos+17] == 0
            if ver >= 0xA1: return buf[pos+16 : pos+20] == "DXTV"
            return 1 <= ReadU32BE(buf, pos+16) <= 16 and buf[pos+20] == 0 and 1 <= buf[pos+21] <= 11
    if ver >= 0x2E:
        if 0xC0000000 <= w0 <= 0xC000FFFF and w1 == 1 and w2 < 0x100000: return true
        if w0 == 1 and w1 in [2,32,33,34,36,0x100,0x104] and 3 <= w2 <= 500000:
            if ver >= 0xA1: return buf[pos+12 : pos+16] == "DXTV"
            return 1 <= w3 <= 16 and buf[pos+16] == 0 and 1 <= buf[pos+17] <= 11
    return false

function HasExplicitVbc(buf, pos, ver):
    if ver < 0x2E: return true
    if pos + 20 > len(buf): return true
    w0, w1, w2, w3 = ReadU32BEArray(buf, pos, 4)
    if 1 <= w0 <= 4:
        if 0xC0000000 <= w1 <= 0xC000FFFF and w2 == 1: return true
        if w1 == 1 and w2 in [1,2,32,33,34,36,0x100,0x104] and 3 <= w3 <= 500000:
            if ver >= 0xA1: return buf[pos+16 : pos+20] == "DXTV"
            return 1 <= ReadU32BE(buf, pos+16) <= 16 and buf[pos+20] == 0 and 1 <= buf[pos+21] <= 11
    return false

function AccumAttr(attr_def, tp, off, state, sequential_if_zero):
    if tp <= 0 or tp >= len(TYPE_SIZES): return
    sz = TYPE_SIZES[tp]
    actual_off = state.stride if (sequential_if_zero and off == 0 and state.stride > 0) else off
    if attr_def == 0 and state.pos_type < 0:  state.pos_type = tp;  state.pos_off = actual_off
    elif attr_def == 1 and state.norm_type < 0: state.norm_type = tp; state.norm_off = actual_off
    elif attr_def == 2 and state.col_type < 0:  state.col_type = tp;  state.col_off = actual_off
    elif attr_def == 5 and state.uv_type < 0:   state.uv_type = tp;   state.uv_off = actual_off
    end = max((state.stride + sz) if sequential_if_zero else 0, actual_off + sz)
    if end > state.stride: state.stride = end

function PatchDdsLinearPitchAndDecode(dds_bytes):
    flags, dh, dw, pitch = ReadU32LEArray(dds_bytes, 8, 4)
    fourcc = dds_bytes[84 : 88]
    blk = 8 if fourcc == "DXT1" else (16 if fourcc in ["DXT3", "DXT5"] else 0)
    mip0_sz = max(1, (dw + 3) >> 2) * max(1, (dh + 3) >> 2) * blk if blk > 0 else 0
    if blk > 0 and (flags & 0x00080000) != 0 and pitch != mip0_sz:
        dds_bytes = Copy(dds_bytes); WriteU32LE(dds_bytes, 20, mip0_sz)
    return DecodeDDSImage(dds_bytes)   // fallback: clamp mips=1 to 128+mip0_sz if full mip chain fails

function ParseHsemPsidMap(bytes, psid):
    pos = psid + 8 + (4 if bytes[psid+8:psid+12] == "ROTV" else 0)
    slen = ReadU32BE(bytes, pos); pos += 4 + slen
    if bytes[pos:pos+4] == "ROTV": pos += 4
    n_ops = ReadU32BE(bytes, pos); pos += 4
    ops = [(ReadU16BE(bytes, pos+i*6), ReadU32BE(bytes, pos+i*6+2)) for i in 0 .. n_ops - 1]; pos += n_ops * 6
    if bytes[pos:pos+4] == "ROTV": pos += 4
    n_grp = ReadU32BE(bytes, pos); pos += 4; mesh_to_mtl = {}
    for _g in 0 .. n_grp - 1:
        pos += 2; nm = ReadU32BE(bytes, pos); pos += 4; mtls = ReadU32BEArray(bytes, pos, nm); pos += nm * 4
        nc = ReadU32BE(bytes, pos); pos += 4; cmds = ReadU32BEArray(bytes, pos, nc); pos += nc * 4
        for (mi, ci) in zip(mtls, cmds):
            for d in [0, 1, -1]:
                if 0 <= ci+d < n_ops and ops[ci+d][0] == 0xB300: mesh_to_mtl[ops[ci+d][1]] = mi; break
    return mesh_to_mtl

function ParseHsemLtmuMaterials(bytes, ltmu, psid, n_dds, nut_names):
    l_ver = ReadU32BE(bytes, ltmu + 4); pos = ltmu + 8 + (4 if bytes[ltmu+8:ltmu+12] == "ROTV" else 0)
    n_mtl = ReadU32BE(bytes, pos); tdml = FindTagBetween(bytes, "TDML", ltmu + 8, psid) or psid or len(bytes)
    mtls = [(White, -1)] * n_mtl
    if l_ver <= 0x20:
        hits = FindSpacedPattern(bytes[ltmu:tdml], 0x7F7F7FFF * 3, min_gap=32, limit=n_mtl)
        for m, h in enumerate(hits):
            mo = ltmu + h - 0x74; tid = ReadI16BE(bytes, mo + 0x61)
            if tid < 0 or tid >= n_dds or IsNonDiffuseNut(nut_names, tid): tid = -1
            col = White
            if tid < 0:
                b, g, r = bytes[mo+0x70], bytes[mo+0x71], bytes[mo+0x72]
                if not (b == 0x7F and g == 0x7F and r == 0x7F) and (b+g+r) > 0: col = (r/255.0, g/255.0, b/255.0)
                elif l_ver >= 0x15 and mo + 0x26E <= tdml: col = ClampValidRGB(ReadF32BE3(bytes, mo + 0x262))
            mtls[m] = (col, tid)
    else:
        hits = FindPattern(bytes[ltmu:tdml], 0x00000004 * 10, limit=n_mtl); ns = 16 if l_ver < 0x78 else 18
        for m, h in enumerate(hits):
            t0 = ReadI32BE(bytes, ltmu + h - ns*4); t4 = ReadI32BE(bytes, ltmu + h - ns*4 + 16)
            tid = -1 if (t0 < 0 or t0 >= n_dds or t0 == t4 or IsNonDiffuseNut(nut_names, t0)) else t0
            mtls[m] = (White, tid)
    return mtls

function DetectLittleEndianF32(buf, data_pos, vbase, vcnt, stride, pos_off, tp):
    if tp not in [3, 4]: return false
    le_bad = 0; be_bad = 0
    for i in 0 .. min(vcnt, 16) - 1:
        o = data_pos + (vbase + i) * stride + pos_off
        for (vals, is_le) in [(ReadF32BE3(buf, o), false), (ReadF32LE3(buf, o), true)]:
            bad = any(not IsFinite(c) or abs(c) > 10000.0 for c in vals) or (0 < Dot(vals,vals) < 1e-12)
            if bad: (le_bad if is_le else be_bad) += 1
    return le_bad < be_bad

function ParseHsemStream(bytes):
    hsem = FindTag(bytes[0 : min(len(bytes), 524288)], "HSEM")
    if hsem < 0: return []
    buf = bytes[0 : min(len(bytes), 64*1024*1024)]
    p = hsem + 4; ver = ReadU32BE(buf, p); p += 4
    if buf[p : p+4] == "ROTV" or ver >= 0xAD: p += 4
    mesh_count = ReadU32BE(buf, p); p += 4
    if mesh_count == 0 or mesh_count > 4096: return []

    ltmu = FindTagFrom(buf, p, "LTMU"); psid = FindTagFrom(buf, p, "PSID")
    limit = ltmu if ltmu > p else (psid if psid > p else len(buf))
    n_logh = max(1, CountTagOccurrencesFrom(buf, psid, "LOGH")) if psid >= 0 else 1

    all_vbs = []; all_ibs = []; rid_to_vb = {}; rid_to_ib = {}; submeshes = []
    for m in 0 .. mesh_count - 1:
        if p + 16 > limit: break
        vb_count = ReadU32BE(buf, p) and advance(p, 4) if HasExplicitVbc(buf, p, ver) else 1
        vb_specs = []
        for slot in 0 .. vb_count - 1:
            pres = ReadU32BE(buf, p); p += 4
            if pres >= 0x80000000:
                p += 8; vb_specs.append(("ref", slot, pres & 0xFFFF))
            elif pres != 0:
                _flags = ReadU32BE(buf, p); nv = ReadU32BE(buf, p+4); p += 8
                state = {pos_type:-1, pos_off:0, norm_type:-1, norm_off:0, col_type:-1, col_off:0, uv_type:-1, uv_off:0, stride:0}
                if ver >= 0xA1:
                    if buf[p : p+4] != "DXTV": break
                    desc_ver = ReadU32BE(buf, p+4); p += 8
                    if desc_ver <= 0x2D:
                        for s in 0 .. 15: AccumAttr(s, buf[p], buf[p+1], state, true); p += 2
                    else:
                        na = ReadU32BE(buf, p); p += 4
                        for _a in 0 .. na - 1: AccumAttr(buf[p], buf[p+1], buf[p+2], state, false); p += 3
                    p += 6
                elif ver < 0x2E:
                    for s in 0 .. 15: AccumAttr(s, buf[p], buf[p+1], state, true); p += 2
                else:
                    na = ReadU32BE(buf, p); p += 4
                    for _a in 0 .. na - 1: AccumAttr(buf[p], buf[p+1], buf[p+2], state, false); p += 3
                vb_obj = {slot:slot, nv:nv, stride:state.stride, data_pos:p, state:state, next_vbase:0, rid:null}
                all_vbs.append(vb_obj); vb_specs.append(("new", slot, vb_obj))
                p += nv * state.stride + 4
            else:
                p += 4; vb_specs.append(("none", slot, null))

        unk1 = ReadU32BE(buf, p); ib_pres = ReadU32BE(buf, p+4); p += 8; cur_ib = null
        if ib_pres >= 0x80000000:
            p += 4; rid = ib_pres & 0xFFFF
            if rid not in rid_to_ib and len(all_ibs) > 0: rid_to_ib[rid] = all_ibs[-1]
            cur_ib = rid_to_ib.get(rid, all_ibs[-1] if len(all_ibs) > 0 else null)
        elif ib_pres != 0:
            _ibf, ic, isz = ReadU32BEArray(buf, p, 3); p += 12
            if isz == 0: isz = 2
            cur_ib = ReadU16BEArray(buf, p, ic) if isz == 2 else ReadU32BEArray(buf, p, ic)
            all_ibs.append(cur_ib); p += ic * isz

        if unk1 != 0:
            p_after = p + 12
            if m + 1 < mesh_count: p = p_after if IsHsemMeshStart(buf, p_after, ver) else p_after + 4
            continue

        ioff = ReadU32BE(buf, p); icnt = ReadU32BE(buf, p+4); vbase = ReadU32BE(buf, p+8)
        vcnt = ReadU16BE(buf, p+16); prim_tp = ReadU16BE(buf, p+18)
        blen = ReadU32BE(buf, p+22); if blen > 256: blen = 0

        resolved = []
        for (kind, slot, val) in vb_specs:
            if kind == "new":
                val.next_vbase = vbase + vcnt; resolved.append(val)
            elif kind == "ref":
                if val not in rid_to_vb:
                    cand = FirstMatch(all_vbs, x => x.slot == slot and x.rid == null and x.next_vbase == vbase and vbase+vcnt <= x.nv)
                        or LastMatch(all_vbs,  x => x.slot == slot and x.rid == null and vbase+vcnt <= x.nv)
                        or LastMatch(all_vbs,  x => x.slot == slot and vbase+vcnt <= x.nv)
                    if cand != null: cand.rid = val; rid_to_vb[val] = cand
                vb_obj = rid_to_vb.get(val)
                if vb_obj != null: vb_obj.next_vbase = max(vb_obj.next_vbase, vbase + vcnt)
                resolved.append(vb_obj)
            else: resolved.append(null)

        if vcnt >= 3 and icnt >= 3 and cur_ib != null and len(resolved) > 0 and resolved[0] != null:
            submeshes.append({mesh_idx:m, vb0:resolved[0], vb1:(resolved[1] if len(resolved)>1 else null),
                              ib:cur_ib, vbase:vbase, vcnt:vcnt, ioff:ioff, icnt:icnt, prim_tp:prim_tp, blen:blen})

        p_after = p + 26 + blen
        if m + 1 < mesh_count:
            post = 76 if ver >= 0x30 else (44 if ver >= 0x2E else 8)
            p = FindNextHsemStart(buf, p_after, ver, [post, 4, 8, 44, 48, 72, 76], limit)

    dds_slices = ExtractHsemDdsSlices(buf, hsem, psid)
    nut_names  = ParseHsemAtemNames(buf, hsem, psid)
    mesh_to_mtl = ParseHsemPsidMap(buf, psid)
    ltmu_mtls   = ParseHsemLtmuMaterials(buf, ltmu, psid, len(dds_slices), nut_names)

    lod0 = submeshes[0 : ceil(len(submeshes) / n_logh)]
    if count(sm in lod0 where sm.blen > 0) >= 3:
        lod0 = [sm for sm in lod0 where sm.blen > 0]

    result = []; seen_bboxes = {}
    for sm in lod0:
        vb0 = sm.vb0; vb1 = sm.vb1; st0 = vb0.state
        use_le = DetectLittleEndianF32(buf, vb0.data_pos, sm.vbase, sm.vcnt, vb0.stride, st0.pos_off, st0.pos_type)
        norm_vb = vb1 if (vb1 != null and vb1.nv == vb0.nv and vb1.state.norm_type >= 0) else vb0
        col_vb  = vb1 if (vb1 != null and vb1.nv == vb0.nv and vb1.state.col_type  >= 0) else vb0
        uv_vb   = vb1 if (vb1 != null and vb1.nv == vb0.nv and vb1.state.uv_type   >= 0) else vb0
        positions = [DecodeVec3(buf, vb0.data_pos + (sm.vbase+i)*vb0.stride + st0.pos_off, st0.pos_type, use_le) for i in 0 .. sm.vcnt-1]
        normals   = [Normalize3(DecodeNormal(buf, norm_vb.data_pos + (sm.vbase+i)*norm_vb.stride + norm_vb.state.norm_off, norm_vb.state.norm_type)) for i in 0 .. sm.vcnt-1]
        colors    = DecodeVertexColorAttr2(buf, col_vb, sm.vbase, sm.vcnt)
        uvs       = [DecodeVec2(buf, uv_vb.data_pos + (sm.vbase+i)*uv_vb.stride + uv_vb.state.uv_off, uv_vb.state.uv_type) for i in 0 .. sm.vcnt-1]
        tris      = DecodeTriangles(sm.ib[sm.ioff : sm.ioff + sm.icnt], sm.vcnt, sm.prim_tp == 1, clockwise_target=false)
        if len(tris) < 3: continue
        bbox = QuantizedBBoxKey(positions, sm.vcnt, len(tris) / 3)
        if bbox not in seen_bboxes:
            seen_bboxes.add(bbox)
            mtl_col, tid = ltmu_mtls[mesh_to_mtl[sm.mesh_idx]] if sm.mesh_idx in mesh_to_mtl else (White, -1)
            mtl_tex = PatchDdsLinearPitchAndDecode(dds_slices[tid]) if tid >= 0 else null
            result.append((positions, normals, colors, uvs, tris, mtl_col, mtl_tex))
    return result
