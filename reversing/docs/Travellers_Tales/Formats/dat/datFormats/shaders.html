Standalone Clean-Room Parser Pseudocode

function ExtractShaderBlobs(buf):
    pos = 0; blobs = []
    while (p := FindTag(buf, b"HSCB" or b"DXBC", pos)) >= 0:
        blobs.append(p)
        pos = p + 4
    return blobs
