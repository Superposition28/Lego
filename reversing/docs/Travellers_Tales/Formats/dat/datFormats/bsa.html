Binary Header (Observed in run_TwoArms.bsa & fallLand.bsa)

.bsa Nu Header Structure
Offset Size Type Field Description
0x00 4 u32le version Constant 2.
0x04..0x0F 12 u16le[] rel_ptrs Relative Nu descriptor pointers (identical convention to .ani/.cut).
0x10..0x1F 16 f32le, u16le[] blend_params Transition duration float (e.g. 28.0f / 45.0f) and state/blend flags.

Standalone Clean-Room Parser Pseudocode

function ParseBsaHeader(buf):
    ver = ReadU32LE(buf, 0)
    blend = ReadF32LE(buf, 0x10)
    return {version: ver, blend_param: blend, size: len(buf)}
