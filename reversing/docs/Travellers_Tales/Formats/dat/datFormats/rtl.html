Scene Lighting · Era 1–3a (LSW1 through Indy 2)

Fixed-stride binary lighting tables defining light positions, directional vectors, RGBA colors, radii, and attenuation curves in Era 1–3a levels before LTMU/HSEM lighting moved into .gsc/.led.

Binary Layout (Version 5 in TCS & Batman 1)

.rtl Light Entry Stride (140 B = 0x8C, Starting at +0x04)
Offset (within Record) Size Type Description
+0x00 (file 0x04) 12 f32le[3] World position / direction float vector.
+0x0C..+0x37 44 f32le[] Normalized RGB color channels, specular/ambient multipliers, and cone/falloff floats.
+0x38..+0x8B 84 f32le/u32le Radius, flags, flicker/shadow parameters, and end padding (0x8C total stride verified between record 0 at 0x04 and record 1 at 0x90).

Filtering, Edge Cases & Unresolved Fields

  • File length 20,356 B matches a fixed maximum light buffer size (145 records + trailer bytes). Zero out trailing unused light slots where flags/radius == 0.

Standalone Clean-Room Parser Pseudocode

function ParseRtl(buf):
    ver = ReadU32LE(buf, 0)
    stride = 140
    lights = []
    for off in range(4, len(buf) - stride + 1, stride):
        px, py, pz = ReadF32LE3(buf, off)
        lights.append({pos: (px, py, pz)})
    return {version: ver, lights: lights}
