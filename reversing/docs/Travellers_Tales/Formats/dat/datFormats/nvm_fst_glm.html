Open-World Simulation · Marvel 1, Hobbit & Dimensions

Trio of big-endian .CC4 spatial simulation containers introduced in LEGO Marvel Super Heroes for Manhattan/Hub AI: VNTT navigation mesh (.nvm), SFTT pedestrian pathways (.fst), and LGTT road traffic (.glm).

Extensions & Tags
.nvm (.CC4VNTT v2), .fst (.CC4SFTT v4), .glm (.CC4LGTT v5/v6)
Note on 4CC Naming
Tags are 4-char reversed big-endian IDs: VNTT = TTNV, SFTT = TTFS, LGTT = TTGL (GridLock).

Standalone Clean-Room Parser Pseudocode

function IdentifyCc4SimContainer(buf):
    sz = ReadU32BE(buf, 0)
    tag = buf[4:12].decode("ascii", "replace")
    ver = ReadU32BE(buf, 12)
    return {tag: tag, version: ver, size: sz}
