Binary Header Observation (LSW1 Xbox)

Observed .ter Header Bytes (Retake_F.ter, 689,900 B)
Offset Size Type Observed Hex / Value Interpretation
0x00 4 u32le 0x00052856 (338,006) Payload size / vertex or grid descriptor count.
0x04 4 u32le 0x00100000 Alignment / grid dimension flags.
0x08..0x1F 24 f32le / packed a0 fb af bd e0 93 b4 3d ... IEEE 754 spatial extent / terrain vertex normal & height tuples (~±0.088..0.038).

Standalone Clean-Room Parser Pseudocode

function ParseTerHeader(buf):
    count_or_sz, flags = ReadU32LE2(buf, 0x00)
    // Remaining grid cells follow at 0x08 (exact stride unconfirmed beyond bounding vecs)
    return {count_or_sz: count_or_sz, flags: flags, payload_size: len(buf) - 8}
