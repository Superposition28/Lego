.res .CC4HSER Resource Header Layout
Offset Size Type Field Description
0x00 4 u32be payload_sz Remaining file size minus 4 (0x1F93 = 8,083 B).
0x04 12 char[12] magic ".CC4HSERHSER" (NuResourceHeader).
0x10 4 u32be version Observed 8.
0x14..0x27 20 u32be[5] counts / str_len Counts (`1, 1, 0x67=103`) and string table offsets (`0x8F`, `0xBAE`) indexing null-separated animation/VO/texture dependencies (`act_swipehvy`, `vo_genfem2_stunned`...).

Filtering, Edge Cases & Unresolved Fields

  • Binary Not Plaintext: Always parse as big-endian .CC4HSER rather than line-by-line text.

Standalone Clean-Room Parser Pseudocode

function ParseRes(buf):
    if buf[4:16] != b".CC4HSERHSER": raise NotRes
    ver = ReadU32BE(buf, 16)
    return {version: ver, strings: ExtractNullAsciiFrom(buf, 0x28)}
