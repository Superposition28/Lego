.lxfml Verified in Dimensions (10 files) & Worlds UTF-8 XML (`versionMajor="5" versionMinor="0"`) listing <Brick>, designID (official LEGO element ID), materials, and 3×4 transformation matrices (stuff\cubes\cubemedone.lxfml, 47,389 B).
PS4 CUSA02985 PKGs Verified in local PS4 fPKGs Three \x7fCNT containers (Base 1.65 GB, Update v01.12 1.68 GB, Classic Space DLC 1.57 MB) with PlayGo (11 chunks), snd0.at9, trophy00.trp, and AES-XTS encrypted outer PFS (magic=20130315, mode=0x000D).
.g1m / .g1t Reference-only (inside encrypted PFS / PC) NTT / Koei-style binary mesh and texture sheets used alongside .CC40TAD (`v-10/-11`).
.chunk Reference-only (inside encrypted PFS / PC) Procedural voxel terrain block chunk arrays storing biome IDs and brick occupancy grids.

Standalone Clean-Room Parser Pseudocode

function ParseLxfmlBricks(xml_text):
    root = ParseXml(xml_text)
    return [(b.attrib["designID"], b.attrib.get("materials")) for b in root.findall(".//Brick")]
