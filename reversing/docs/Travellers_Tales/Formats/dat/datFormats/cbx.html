Binary Header Layout (Observed Across BM2 & Marvel 1)

.cbx (!B0X) 20-Byte Header
Offset Size Type Field Description
0x00 4 char[4] magic "!B0X" (0x21423058).
0x04 4 u32le decoded_pcm_bytes Uncompressed 16-bit PCM size in bytes (e.g. 0x2B48 = 11,080 B in BM2; 112,874 B in Marvel 1).
0x08 4 u32le sample_rate Sampling rate in Hz (22050 = 0x5622).
0x0C 4 u32le flags_or_seed Codec parameter / bitrate state word (e.g. 0xED95B9D8 / 0x466A5FD0).
0x10+ var bytes chatterbox_bitstream Custom sub-band CELP / ChatterBoX frame packets.

Standalone Clean-Room Parser Pseudocode

function ParseCbxHeader(buf):
    if buf[0:4] != b"!B0X": raise NotCbx
    pcm_sz, rate, flags = ReadU32LE3(buf, 4)
    return {pcm_bytes: pcm_sz, sample_rate: rate, payload: buf[0x10:]}
