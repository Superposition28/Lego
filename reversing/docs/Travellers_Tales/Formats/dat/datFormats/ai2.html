Binary Layout of .aib (.CC4IATT)

.aib Navigation Sector Layout (Observed in aiworld_0_sector_5.aib)
Offset Size Type Field Description
0x00 4 u32be payload_sz Remaining file size (0x384 = 900 B).
0x04 8 char[8] magic ".CC4IATT" (TT AI Tag).
0x0C 4 u32be version 6 (BM2) or 8 (LOTR).
0x10 4 u32be node_count Number of nav nodes (17 in sector 5).
0x14+ 20 B/node u32be, f32be[3], u32be NavNode[] 0x00000010 flag + (x, y, z) world coordinate floats + connectivity/mask bits.

Standalone Clean-Room Parser Pseudocode

function ParseAib(buf):
    if buf[4:12] != b".CC4IATT": raise NotAib
    ver, cnt = ReadU32BE2(buf, 12)
    nodes = []
    for i in 0 .. cnt - 1:
        off = 20 + i * 20
        fl = ReadU32BE(buf, off); x, y, z = ReadF32BE3(buf, off + 4)
        nodes.append({flags: fl, pos: (x, y, z)})
    return nodes
