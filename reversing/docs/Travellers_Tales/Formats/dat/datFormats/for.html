Binary scatter definitions placing grass, debris, and breakable window/foliage clusters on named level surfaces.

Observed Record Layout (new_town.for, TCS)

.for Header & Scatter Entries
Offset Size Type Field Description
0x00 4 u32le version 6 (TCS), 18 (0x12 in LSW1).
0x04 4 u32le count Scatter entry count (358 = 0x166 in new_town.for).
0x08..0x61 90 struct ScatterEntry[0] 20B null-padded name + bounds/density flags + floats 3.0, 10.0, 1.0, 1.0. Subsequent entries compact-prefixed by length/flags.

Standalone Clean-Room Parser Pseudocode

function ParseForHeader(buf):
    ver, cnt = ReadU32LE2(buf, 0)
    return {version: ver, entry_count: cnt, first_name: ReadNullAscii(buf, 8, 24)}
