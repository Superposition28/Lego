.gsc / .nux / .nx2 / .nus (NuScene Compiled Scene Geometry)

Category: 3D Graphics & Scene · Scope: Universal (All TT Engine Generations 2005–2024; .nux/.nus in LSW1 Xbox, .nx2 in LSW2 Xbox, .nup in LSW1 PC/GCN; _nxg.gsc / _dx11.gsc in Era 3–4)

Cross-Generation Master Specification · TT Games Engine

Compiled static scene geometry, level rooms, architectural meshes, props, material sets, and visibility lists. This parent document combines all Traveller's Tales engine generations (Classic Nu2 / NU20 through Next-Gen HSEM v0x04..0xAD+) into one self-contained specification so a clean-room parser/converter can be written without external source code. Individual game documentation pages cover only the variant shipped in that game.

2. Classic NU20 Scene Geometry (Era 1–2)

OffsetSizeTypeFieldDescription
0x004uint32lenu20_relOffset from 0x04 to "NU20" (nu_off = nu20_rel + 4).
0x042uint16len_texTexture slot count before vertex buffers.
0x06..varTexBlock[]InlineDDS24-byte header (int32le width_signed at +0x00, uint32le dds_size at +0x14) + "DDS " bytes. Cubemaps (width_signed < 0) count as 6 slots; advance 24 + dds_size.
NextvarVBTableVertexBuffersuint16le n_vb records of [uint32le size, uint8 data[size]]. n_vb == 0 = empty scene/locator.
NextvarIBTableIndexBuffersuint16le n_ib records of [uint32le size, uint16le indices[size / 2]].
nu_off..EOFvarNU20/GSNHSceneGraphLocate "GSNH". Self-relative pointers at gsnh + 280 yield Display Header (cmd_base, n_groups, p_groups). Iterate groups (or 0x82 scan) to extract 56-byte draw descriptors.
  • Group & Command Chain: 12 B group at goff = p_groups + g*12 -> int32le cnt, +4 mtls_rel -> int32le mtls[cnt] material table indices, +8 cmds_rel -> array of cmd_idx into 16 B command records (opcode, desc_rel, z0, z1) -> 56 B draw descriptor desc[0..13] at c_off + 4 + desc_rel.
  • 0x380 Material Records: Scan cmd_base until opcode == 0x8E; every opcode == 0x380 resolves a material struct at mo = c_off + 4 + c1 holding +0x54 float32le[3] rgb and +0x74 int16le tid (index into dds_by_slot).
  • 56 B Descriptor & Vertex Layout: desc[0] (4/5=List, 6=Strip), desc[1]=tri_cnt, desc[2]&0xFF=stride (24..48), desc[5]=vbase, desc[6]=vcnt, desc[7]=ioff, desc[8]=ib_idx, desc[9]=vb_idx. is_skinned_fmt = (desc[2] > 0) or (stride >= 40). Per vertex at vi*stride: +0x00 f32le[3] pos; +0x0C u8[3] unsigned normal (b/127.5 - 1.0) when stride >= 24; when stride >= 28, uv_off = (stride - 16) if is_skinned_fmt else (stride - 8) gives top-left UV0 and col_off = uv_off - 4 (or stride - 4 when stride == 24) stores 4-byte baked AO/vertex color (0x7F = 1.0).

3. Next-Gen .CC4 / HSER / 02UN HSEM Scene Stream (Era 3–4)

Field / RecordOffset / RuleExact Big-Endian Binary Encoding
HSEM HeaderFirst 512 KB"HSEM" (4 B) + uint32be ver + optional 4 B (if "ROTV" or ver >= 0xAD) + uint32be mesh_count (0 = empty locator scene). Stream stops at first "LTMU"/"PSID"; count "LOGH" from "PSID" -> n_logh = max(1, count).
vb_count & SlotsPer mesh pExplicit uint32be when ver < 0x2E or HasExplicitVbc matches; else 1. pres >= 0x80000000 skips 8 B (back-ref rid = pres & 0xFFFF); pres == 0 skips 4 B; inline VB reads flags, nv, versioned decl (16×2B v<0x2E; n_attr×3B 0x2E..0x30; "DXTV"+desc_ver+table+6B v>=0xA1), then nv * stride bytes + 4 B offset.
unk1 & IB SlotAfter VB slotsRead uint32be unk1, uint32be ib_pres. ib_pres >= 0x80000000 skips 4 B and resolves ib_pres & 0xFFFF; else reads flags, ic, isz (0->2) and ic big-endian indices. When unk1 != 0, skip 12 B (+0/4 align) as shadow/depth prepass.
26 B Draw SliceWhen unk1 == 0ioff (u32be), icnt (u32be), vbase (u32be), vcnt (u16be @ +0x10), prim_tp (u16be @ +0x12: 0=List, 1=Strip), blen (u32be @ +0x16) + blen bytes. Trailer to next mesh: 8 B (<0x2E), 44 B (0x2E..0x2F), 76 B (>=0x30).

4. Materials, Embedded DDS Textures & Shading Model

Static .gsc room/prop assets follow FinalAlbedo = MaterialColor * VertexColor * DiffuseTexture_DDS (with full Next-Gen container layout documented in .ghg Materials & Shading Model):

  • Next-Gen HSEM Materials & Textures: Extract standard 128-byte "DDS \x7c\x00\x00\x00" slices from [0..hsem_pos] and [psid..EOF] (patching dwPitchOrLinearSize @ +0x14 to mip0_bytes when DDSD_LINEARSIZE is set with an inflated pitch), parse ATEM .nut paths (filtering /undersides/, mask_, sbmask_, /normals/, _n.nut, _nrm.nut, specular, dummylightmap, capenormal), resolve mesh_idx -> mtl_idx via PSID 0xB300 opcodes + group mtls[], and decode LTMU materials (l_ver <= 0x20: mo+0x61 i16be tid, mo+0x70 BGRA, mo+0x262 f32be[3]; l_ver > 0x20: 00000004*10 anchor preceded by 16 or 18 i32be texture slots, diffuse in t0 when t0 != t4). Render diffuse textures opaque (alpha channel frequently stores specular/AO).

5. Vertex Attributes, Endian Detection & Winding

  • TYPE_SIZES: [0, 4, 8, 12, 16, 4, 8, 4, 4, 4, 4, 2]. Semantic roles: 0=Position, 1=Normal, 2=VertexColor (tp in {7,8,9}, 0x7F = 1.0, defaulting all-zero 0,0,0 to white (1,1,1)), 5=UV0. If vb0 lacks normals/colors/UVs and vb1.nv == vb0.nv, read them from vb1 over vbase .. vbase + vcnt.
  • Types & Winding: Auto-detect LE vs BE for Float3/4 across 16 sample verts; decode Half4/Half2 as IEEE-754 binary16; decode UByteN4 normals as unsigned (b / 127.5) - 1.0. Slice indices cur_ib[ioff : ioff + icnt] are 0-based relative to vbase (CCW: (a,b,c) list; (a,b,c) even / (b,a,c) odd strip; flip to CW for Godot SurfaceTool). Keep LOD 0 (ceil(len(submeshes) / n_logh)) and deduplicate identical bounding boxes.

6. Complete Standalone Parser Pseudocode (Multi-Era .gsc)

CONST TYPE_SIZES = [0, 4, 8, 12, 16, 4, 8, 4, 4, 4, 4, 2]

function ParseGscScene(bytes):
    prims = ParseNu20Scene(bytes)
    if len(prims) > 0: return prims
    return ParseHsemSceneStream(bytes)

function ParseNu20Scene(bytes):
    if len(bytes) < 8: return []
    nu_off = ReadU32LE(bytes, 0x00) + 4
    if nu_off < 8 or nu_off + 8 > len(bytes) or bytes[nu_off : nu_off + 4] != "NU20": return []
    n_tex = ReadU16LE(bytes, 0x04); pos = 0x06; tex_idx = 0; dds_by_slot = {}
    while tex_idx < n_tex and pos + 28 <= nu_off:
        if bytes[pos + 24 : pos + 28] != "DDS ": break
        w_signed = ReadI32LE(bytes, pos); dds_size = ReadU32LE(bytes, pos + 20)
        if w_signed > 0 and dds_size > 128: dds_by_slot[tex_idx] = bytes[pos + 24 : pos + 24 + dds_size]
        tex_idx += (6 if w_signed < 0 else 1); pos += 24 + dds_size
    n_vb = ReadU16LE(bytes, pos); pos += 2; vbs = []
    for _ in 0 .. n_vb - 1: sz = ReadU32LE(bytes, pos); pos += 4; vbs.append(bytes[pos : pos + sz]); pos += sz
    n_ib = ReadU16LE(bytes, pos); pos += 2; ibs = []
    for _ in 0 .. n_ib - 1: sz = ReadU32LE(bytes, pos); pos += 4; ibs.append(ReadU16LEArray(bytes, pos, sz/2)); pos += sz
    if len(vbs) == 0 or len(ibs) == 0: return []

    tail = bytes[nu_off : len(bytes)]; gsnh = FindTag(tail, "GSNH")
    if gsnh < 0 or gsnh + 420 > len(tail): return []
    hdr_off  = gsnh + 280 + ReadI32LE(tail, gsnh + 280)
    cmd_base = hdr_off + 8  + ReadI32LE(tail, hdr_off + 8)
    n_groups = ReadI32LE(tail, hdr_off + 16); p_groups = hdr_off + 20 + ReadI32LE(tail, hdr_off + 20)
    nu_mtls = ReadNu380Materials(tail, cmd_base)   // scan cmd_base until 0x8E; 0x380 -> (+0x54 RGB, +0x74 i16 tid)

    descs = []; seen_cmds = {}
    for g_idx in 0 .. n_groups - 1:
        goff = p_groups + g_idx * 12; cnt = ReadI32LE(tail, goff)
        p_mtls = goff + 4 + ReadI32LE(tail, goff + 4); p_cmds = goff + 8 + ReadI32LE(tail, goff + 8)
        for k in 0 .. cnt - 1:
            m_idx = ReadI32LE(tail, p_mtls + k * 4); c_idx = ReadI32LE(tail, p_cmds + k * 4)
            if c_idx in seen_cmds: continue
            c_off = cmd_base + c_idx * 16; t_off = c_off + 4 + ReadI32LE(tail, c_off + 4)
            desc = ReadI32LEArray(tail, t_off, 14)
            if desc[0] in [4,5,6] and 0 < desc[1] < 200000 and (desc[2] & 0xFF) in [24,28,32,36,40,44,48]:
                seen_cmds.add(c_idx); descs.append((desc, m_idx))
    if len(descs) == 0:
        for off in range(max(0, gsnh - 250000), gsnh, 4):
            c0, rel, z0, z1 = ReadI32LEArray(tail, off, 4)
            if c0 == 0x82 and z0 == 0 and z1 == 0 and 0 < rel < 200000:
                desc = ReadI32LEArray(tail, off + 4 + rel, 14)
                if desc[0] in [4,5,6] and 0 < desc[1] < 200000: descs.append((desc, -1))

    out = []; seen_ranges = {}; seen_bboxes = {}
    for (desc, m_idx) in descs:
        prim_tp = desc[0]; tri_cnt = desc[1]; stride = desc[2] & 0xFF
        vbase = desc[5]; vcnt = desc[6]; ioff = desc[7]; ib_idx = desc[8]; vb_idx = desc[9]
        if (vb_idx, vbase, vcnt, ioff) in seen_ranges: continue
        idx_cnt = (tri_cnt + 2) if prim_tp == 6 else (tri_cnt * 3)
        if (vbase + vcnt) * stride > len(vbs[vb_idx]) or ioff + idx_cnt > len(ibs[ib_idx]): continue
        is_skinned_fmt = (desc[2] > 0) or (stride >= 40); has_uv = (stride >= 28)
        uv_off = (stride - 16) if is_skinned_fmt else (stride - 8)
        col_off = (uv_off - 4) if has_uv else (stride - 4)
        positions = [ReadF32LE3(vbs[vb_idx], vi*stride) for vi in vbase .. vbase+vcnt-1]
        normals   = [Normalize3(vbs[vb_idx][vi*stride+12]/127.5-1.0, vbs[vb_idx][vi*stride+13]/127.5-1.0, vbs[vb_idx][vi*stride+14]/127.5-1.0) for vi in vbase .. vbase+vcnt-1] if stride >= 24 else []
        colors    = [DecodeVertexColorByte4(vbs[vb_idx], vi*stride + col_off) for vi in vbase .. vbase+vcnt-1] if (16 <= col_off and col_off+4 <= stride) else []
        uvs       = [ReadF32LE2(vbs[vb_idx], vi*stride + uv_off) for vi in vbase .. vbase+vcnt-1] if has_uv else []
        tris      = DecodeTriangles(ibs[ib_idx][ioff : ioff + idx_cnt], vcnt, prim_tp == 6, false)
        if len(tris) < 3: continue
        bbox = QuantizedBBoxKey(positions, vcnt, len(tris) / 3)
        if bbox not in seen_bboxes:
            seen_ranges.add((vb_idx, vbase, vcnt, ioff)); seen_bboxes.add(bbox)
            mtl_col, mtl_tex = ResolveNuMaterial(nu_mtls, dds_by_slot, m_idx)
            out.append((positions, normals, colors, uvs, tris, mtl_col, mtl_tex))
    return out

function ParseHsemSceneStream(bytes):
    hsem = FindTag(bytes[0 : min(len(bytes), 524288)], "HSEM")
    if hsem < 0: return []
    buf = bytes[0 : min(len(bytes), 64*1024*1024)]
    p = hsem + 4; ver = ReadU32BE(buf, p); p += 4
    if buf[p : p+4] == "ROTV" or ver >= 0xAD: p += 4
    mesh_count = ReadU32BE(buf, p); p += 4
    if mesh_count == 0 or mesh_count > 4096: return []

    ltmu = FindTagFrom(buf, p, "LTMU"); psid = FindTagFrom(buf, p, "PSID")
    limit = ltmu if ltmu > p else (psid if psid > p else len(buf))
    n_logh = max(1, CountTagOccurrencesFrom(buf, psid, "LOGH")) if psid >= 0 else 1

    all_vbs = []; all_ibs = []; rid_to_vb = {}; rid_to_ib = {}; submeshes = []
    for m in 0 .. mesh_count - 1:
        if p + 16 > limit: break
        vb_count = ReadU32BE(buf, p) and advance(p, 4) if HasExplicitVbc(buf, p, ver) else 1
        vb_specs = []
        for slot in 0 .. vb_count - 1:
            pres = ReadU32BE(buf, p); p += 4
            if pres >= 0x80000000:
                p += 8; vb_specs.append(("ref", slot, pres & 0xFFFF))
            elif pres != 0:
                _flags = ReadU32BE(buf, p); nv = ReadU32BE(buf, p+4); p += 8
                state = ParseDeclByVersion(buf, &p, ver)   // tracks attr_def 0,1,2,5 across 16x2B / n*3B / DXTV+6B
                vb_obj = {slot:slot, nv:nv, stride:state.stride, data_pos:p, state:state, next_vbase:0, rid:null}
                all_vbs.append(vb_obj); vb_specs.append(("new", slot, vb_obj))
                p += nv * state.stride + 4
            else:
                p += 4; vb_specs.append(("none", slot, null))

        unk1 = ReadU32BE(buf, p); ib_pres = ReadU32BE(buf, p+4); p += 8; cur_ib = null
        if ib_pres >= 0x80000000:
            p += 4; rid = ib_pres & 0xFFFF
            if rid not in rid_to_ib and len(all_ibs) > 0: rid_to_ib[rid] = all_ibs[-1]
            cur_ib = rid_to_ib.get(rid, all_ibs[-1] if len(all_ibs) > 0 else null)
        elif ib_pres != 0:
            _ibf, ic, isz = ReadU32BEArray(buf, p, 3); p += 12
            if isz == 0: isz = 2
            cur_ib = ReadU16BEArray(buf, p, ic) if isz == 2 else ReadU32BEArray(buf, p, ic)
            all_ibs.append(cur_ib); p += ic * isz

        if unk1 != 0:
            p_after = p + 12
            if m + 1 < mesh_count: p = p_after if IsHsemMeshStart(buf, p_after, ver) else p_after + 4
            continue

        ioff = ReadU32BE(buf, p); icnt = ReadU32BE(buf, p+4); vbase = ReadU32BE(buf, p+8)
        vcnt = ReadU16BE(buf, p+16); prim_tp = ReadU16BE(buf, p+18)
        blen = ReadU32BE(buf, p+22); if blen > 256: blen = 0
        resolved = ResolveSharedVBs(vb_specs, all_vbs, rid_to_vb, vbase, vcnt)   // exact next_vbase == vbase match
        if vcnt >= 3 and icnt >= 3 and cur_ib != null and len(resolved) > 0 and resolved[0] != null:
            submeshes.append({mesh_idx:m, vb0:resolved[0], vb1:(resolved[1] if len(resolved)>1 else null),
                              ib:cur_ib, vbase:vbase, vcnt:vcnt, ioff:ioff, icnt:icnt, prim_tp:prim_tp})

        p_after = p + 26 + blen
        if m + 1 < mesh_count:
            post = 76 if ver >= 0x30 else (44 if ver >= 0x2E else 8)
            p = FindNextHsemStart(buf, p_after, ver, [post, 4, 8, 44, 48, 72, 76], limit)

    dds_slices  = ExtractHsemDdsSlices(buf, hsem, psid)
    nut_names   = ParseHsemAtemNames(buf, hsem, psid)
    mesh_to_mtl = ParseHsemPsidMap(buf, psid)
    ltmu_mtls   = ParseHsemLtmuMaterials(buf, ltmu, psid, len(dds_slices), nut_names)
    lod0 = submeshes[0 : ceil(len(submeshes) / n_logh)]
    return EmitDecodedHsemPrimitives(buf, lod0, mesh_to_mtl, ltmu_mtls, dds_slices)
