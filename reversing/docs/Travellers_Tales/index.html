Traveller's Tales Engine & Format Reference (2005–2024)

Unified cross-generation specification covering 53 format families across all seven Traveller's Tales engine eras (Nu2 → Nu2 HD → Early NXG → Mature NXG → Open-World NXG → Zeus Late NXG → NTT / Double Eleven Remasters). For game-specific subsets, open the Top-Level Game Hub.

Pipeline Format Coverage

Verified directly against extracted PS3, Xbox 360, Original Xbox, and PC builds (plus external reference parsers where noted).

  • Verified Binary & Structural Specs (50)Dissected directly from extracted PS3/Xbox/X360/PC files with byte-offset tables & standalone pseudocode.
  • Partial / Hardware-Specific (2)Container, header & crypto verified; proprietary GPU ISA microcode (HSCB) or write-key derivation external.
  • Reference-Documented Only (1)Documented from TTGames-Explorer-Rebirth / TTModding-Docs without local source builds (.CC40TAD, .g1m, .g1t, .chunk).
