# RemakeEngine Integration Analysis: `TTGames-Explorer-Rebirth` & `EngineNet.GameFormats`

This document analyzes the C# codebase of [`reversing/ExternalTools/TTGames-Explorer-Rebirth`](file:///a:/RemakeEngine/Main/EngineApps/Games/Lego/reversing/ExternalTools/TTGames-Explorer-Rebirth/src/TTGamesExplorerRebirth.sln) alongside our empirical reverse-engineering findings and maps out how TT Games format parsers can transition from per-module Lua scripts ([`operations/TtArchiveResearch.lua`](file:///a:/RemakeEngine/Main/EngineApps/Games/Lego/operations/TtArchiveResearch.lua)) into native C# handlers inside [`EngineNet/source/GameFormats`](file:///a:/RemakeEngine/Main/EngineNet/source/GameFormats/EngineNet.GameFormats.csproj) and [`EngineNet/source/Core/DiscImages`](file:///a:/RemakeEngine/Main/EngineNet/source/Core/DiscImages/IsoFactory.cs).

## 1. Existing RemakeEngine Infrastructure (`EngineNet`)

1. **Optical Disc Extraction (`EngineNet.Core.DiscImages`):**
   - [`IsoFactory.cs`](file:///a:/RemakeEngine/Main/EngineNet/source/Core/DiscImages/IsoFactory.cs), [`XdvdfsReader.cs`](file:///a:/RemakeEngine/Main/EngineNet/source/Core/DiscImages/Readers/XdvdfsReader.cs), and [`Iso9660Reader.cs`](file:///a:/RemakeEngine/Main/EngineNet/source/Core/DiscImages/Readers/Iso9660Reader.cs) already support:
     - Xbox 360 `XGD3` (`0x02080000`) and `XGD2` (`0x0FD90000`)
     - Original Xbox `XGD1` (`0x18300000`) and trimmed `XISO` (`0x00000000`) — verified on *LSW1* and *LSW2* Xbox XISOs
     - PlayStation 3 hybrid ISO-9660/UDF (`PS3_HYBRID`) and PlayStation 2 ISO-9660 (`PS2_ISO9660`) — verified on *LSW1*, *LSW2*, *HP 1–4*, *HP 5–7*, and *LEGO Dimensions* ISOs.
2. **Native Format Parsers (`EngineNet.GameFormats`):**
   - [`EngineNet.GameFormats.csproj`](file:///a:/RemakeEngine/Main/EngineNet/source/GameFormats/EngineNet.GameFormats.csproj) targets `net10.0` (`AssemblyName = EngineNet.Formats`) and **already references the exact same imaging/texture packages** used by `TTGamesExplorerRebirthLib`:
     - `SixLabors.ImageSharp` (`4.1.2`)
     - `BCnEncoder.Net` (`2.3.0`)
     - `BCnEncoder.Net.ImageSharp` (`1.1.3`)
   - Note that `TTGamesExplorerRebirthLib` embeds a local copy of `BCnEncoder.Net` under `Formats/DDS/BCnEncoder.Net/`. When integrating into `EngineNet.GameFormats`, that embedded copy can be dropped in favor of the NuGet package already referenced by `EngineNet.GameFormats.csproj`.

## 2. Code Audit of `TTGamesExplorerRebirthLib` vs. Empirical Findings

Inspecting [`TTGamesExplorerRebirthLib`](file:///a:/RemakeEngine/Main/EngineApps/Games/Lego/reversing/ExternalTools/TTGames-Explorer-Rebirth/src/TTGamesExplorerRebirthLib/TTGamesExplorerRebirthLib.csproj) (MIT License) reveals clean, self-contained C# parsers for 18 TT Games format/compression components, plus several important edge cases where our empirical research across *LSW1*, *LSW2*, *HP 1–4/5–7*, *Batman 2*, and *LEGO Dimensions* provides critical improvements:

| **`.DAT` Archive** | [`Formats/DAT/DATArchive.cs`](file:///a:/RemakeEngine/Main/EngineApps/Games/Lego/reversing/ExternalTools/TTGames-Explorer-Rebirth/src/TTGamesExplorerRebirthLib/Formats/DAT/DATArchive.cs) | Classic TOC (`v-2`..`v-5`) and `.CC40TAD` (`v-8`..`v-11`) | **1. Era 1–2 TOC `v-1` (*LSW1* & *LSW2* PS2):** `DATArchive.cs` unconditionally reads `fnv1aFilesList` (`uint32[filesCount1]`) after the string table. ## 3. Recommended Phased Roadmap for `EngineNet.GameFormats` Integration

Following the pattern established by [`EngineNet/source/GameFormats/p3d/Run.cs`](file:///a:/RemakeEngine/Main/EngineNet/source/GameFormats/p3d/Run.cs) and [`EngineNet/source/GameFormats/txd/Run.cs`](file:///a:/RemakeEngine/Main/EngineNet/source/GameFormats/txd/Run.cs):

1. **Phase 1 — Keep Game-Specific Workflows in Lua, Shared Research in `operations/TtArchiveResearch.lua`:**
   - Continue validating new game ISOs and archive variants via Lua operations and QuickBMS scripts while collecting representative test vectors across eras.
2. **Phase 2 — Native Archive & Codec Layer (`EngineNet.GameFormats.TtGames.Archives`):**
   - Port a unified, thread-safe `TtDatReader` (`TOC v-1`..`v-12`, `.HDR`, `CMP2` LZMA, `.datwin` LZHAM), `TtPakReader` (`0x1234567A` / `RFPK`), `TtPkWinReader` (`.pkiwin`/`.pkdwin` + `LHPC_pk_paths.txt`), and `TtFibReader` (`FUSE1.00`) into `EngineNet.GameFormats`, replacing static state in `UnLZ2K` with thread-local/instance buffers for parallel extraction.
3. **Phase 3 — Native Asset Converters (`EngineNet.GameFormats.TtGames.Assets`):**
   - Expose `cbx` -> `.wav` (`CBX.cs`), `nxg_textures` / `tsh` / `ft2` -> `.dds`/`.png` (`NXGTextures.cs`, `TSH.cs`, `FT2.cs` using `EngineNet.GameFormats`'s existing `BCnEncoder.Net` and `SixLabors.ImageSharp`), `edfile` -> `.json` (`EdFile.cs`), and `ghg`/`gsc` -> `.gltf`/`.obj` (`NuCore` + Sluicer's `ExtractPcGHG` / `ExtractNxgMESH` / `ExtractDx11MESH`).
